# character_assessment — 인성 질문 은행 (2026-11-09)

AI 면접 기본 질문 8개 중 **인성 2개**를 여기서 뽑는다. 원문을 그대로 쓰지 않고, **인성 다듬기 에이전트**가 지원자 직무·이력서·공고에 맞게 상황 배경만 바꾼 뒤 출제한다(역량·묻는 핵심은 그대로).

- 형식은 임시(md). 바뀔 수 있다.
- 파일: 이 폴더의 `*.md` 중 `README.md`를 뺀 전부. 문항 = `## ` 제목 하나 + 바로 아래 메타 줄 + 항목 목록.
- 언어: 원문 한국어. 영어판은 질문 은행 sync 때 번역 에이전트가 만든다(`lang=ko`).

## 문항 형식

```
## CA-001 협업 — 의견 충돌 조율
<!--meta: id=CA-001; competency=협업; dup_group=p-conflict; level=신입|경력; lang=ko; eval_items=logic,delivery,fit-->
- 질문: 팀 프로젝트에서 의견이 충돌했을 때 어떻게 조율했는지 한 가지 사례를 들어 설명해 주세요.
- 의도: 갈등을 피하지 않고 근거로 합의를 만드는지
- 좋은 답변 신호: 구체적 상황 / 상대 의견을 들은 방법 / 합의 기준 / 결과와 배운 점
- 파고들 지점: 결국 누구 의견으로 갔나, 그 기준은 무엇이었나
- 맞춤 범위: 상황 배경만 지원 직무에 맞게 바꾼다(예: 팀 프로젝트 → 모델 개발 프로젝트)
- 바꾸면 안 되는 것: 역량(협업), 실제 사례를 요구하는 형태
```

| 칸 | 필수 | 쓰는 곳 |
|---|---|---|
| `id` | 예 | 출처 기록(`gen_method=character:<id>`). 번호는 바꾸지 않고 추가만 |
| `competency` | 예 | 같은 면접에서 같은 역량 2번 금지 |
| `dup_group` | 예 | 비슷한 문항 묶음(같은 묶음은 한 면접에 1개) |
| `level` | 아니오 | 신입·경력 구분(비우면 모두) |
| `질문` | 예 | 원문 |
| `의도` | 예 | 다듬기 에이전트가 지킬 평가 의도 |
| `좋은 답변 신호` | 권장 | 꼬리질문(빠진 신호 묻기)·평가 근거 |
| `파고들 지점` | 권장 | 꼬리질문 |
| `맞춤 범위` / `바꾸면 안 되는 것` | 권장 | 다듬기 에이전트의 허용·금지 범위 |

차단 목록(나이·가족·학벌·출신 등, `questions.BLOCKLIST`)에 걸리는 문장은 쓰지 않는다. 다듬은 결과도 코드가 다시 검사한다.
