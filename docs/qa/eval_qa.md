# headhunterAI 현재 AI 평가지표 (2026-11-12)

지금 쓰고 있는 AI 품질 지표와 측정 주기만 정리한다. 측정 결과는 `eval_runs/`(실행마다 json·md·xlsx)에 있다.
2026-11-12 실행이 **첫 기준선**이다.

## 1. 통과 기준 (세 겹)

1. **하드 제약**: M-36(대외비 누출)·M-38(인용)·M-41(금지 내용)은 위반 0건. 1건이라도 나오면 실패.
2. **평균 목표 + 95% 신뢰구간 하한**: 루브릭 지표(M-33·M-39)는 평균 ≥4.0, 95% CI 하한 ≥3.7.
3. **회귀 허용 폭** (다음 실행부터): 기준선 대비 점수 −0.2점, 비율 −5%p보다 더 나빠지면 실패.

- 통계: 평균의 CI는 부트스트랩(B=5000), 비율의 CI는 Wilson 구간.
- 판정 모델(LLM-as-judge)은 로컬 Ollama만 쓴다. 기본은 `qwen3:8b`. 6GB GPU에서는 `qwen3:4b`로 대신할 수 있고, 그때는 결과에 자기 평가 편향 가능성을 적는다.

## 3. AI 리포트 지표 (M-38~M-44)

| ID | 대상 | 지표 | 측정 방법 | 목표 |
|---|---|---|---|---|
| M-38 | 리포트 | 채점 인용(quote)이 답변 원문의 부분 문자열인지 | 코드 | 1.00(하드) |
| M-38b | 리포트(보조) | 리포트 문장에서 따옴표로 감싼 구절이 답변 원문의 부분 문자열인지 | 코드 | 1.00 |
| M-39 | 리포트 | 루브릭 평균(사실 정확성·구체성·실행 가능성·어조·점수와 일관성) | 판정 모델 1~5 | ≥4.0, CI 하한 ≥3.7 |
| M-40 | 리포트 | 점수와 서술이 맞는지(강점 = 상위 항목, 개선점 = 하위 항목) | 코드(키워드), 보조로 판정 라벨 | ≥0.90 |
| M-41 | 리포트 | 금지 내용(합불 언급·입력에 없는 두 자리 이상 수치·인적 특성) | 코드 | 0건(하드) |
| M-42 | 리포트 | 템플릿으로 대체된 비율(코치 코멘트 또는 요약) | 코드 | ≤0.20 |
| M-43 | 리포트 | 생성 성공률(예외 없이 모든 칸을 채움) | 코드 | ≥0.95 |

- 보조 확인: **변별력**. 답변 수준(우수 > 보통 > 미흡 > 짧음·주제 이탈)에 따라 리포트의 AI 면접 점수가 단조롭게 내려가는지 본다(Spearman).

## 4. 골든셋 · 운영 관측 지표 (M-45~M-54)

PRD v0.13 6.3.9. 골든셋 스크립트 `backend/tools/build_golden_sets.py`(G-검색 질의·G-질문 생성만 OpenAI — 외부 AI 예외 ④, 판정·임베딩은 로컬) · 꼬리질문 지연 `backend/tools/eval_followup.py`. '목표 없음'은 통과·미달을 판정하지 않고 기록·경보만 한다.
