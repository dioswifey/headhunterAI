# job_posting_resources — 공개 레포에서 제외된 디렉토리

원본 프로젝트에서 이 디렉토리에는 사람인·원티드에서 수집한 **실제 채용공고 200건**이 들어 있고,
공고 RAG(`app/agents/job_posting_graph.py`)의 적재 원본으로 쓰인다.

공개 레포에서는 **의도적으로 제외했다.** 실존 기업의 공고 본문이고 일부 파일에
채용담당자 이메일 주소가 포함돼 있어, 재배포가 개인정보 보호와 각 사이트 이용약관에 모두 걸린다.

`docker-compose.yml`이 이 경로를 볼륨으로 마운트하기 때문에 디렉토리 자체는 남겨 둔다.
비어 있으면 `job_posting_graph`의 `scan` 노드가 적재할 대상을 찾지 못하고 그대로 종료한다
(조건부 엣지 `_after_scan` → `END`). 나머지 그래프와 사내문서 RAG는 영향 없이 동작한다.

직접 채워 보려면 `backend/tools/collect_jobs.py`가 수집 스크립트다.
