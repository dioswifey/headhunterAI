# dummies_resume — 지원자 테스트용 더미 이력서

- 2026-11-20 신설(사용자 지시). 지원자 화면 테스트(이력서 업로드 → OCR·구조화 → 확인 → 맞춤 질문)에 쓰는 **가상 이력서**만 둔다.
- 모든 이름·학교·회사·경력·수치는 가상 설정이다. 실제 지원자 데이터·실존 인물 정보를 넣지 않는다.
- **납품은 PDF**(사용자 지시 2026-11-20 "md로 주지 말고 이제부터 pdf로"): 직무 폴더에는 PDF만 둔다.
  - `AI_AX/` — AI/AX 엔지니어 · `01_한도윤_제조AIAX.pdf`(제조 비전 검사 — 도메인 불일치 대조군) · `02_윤세린_LLM상담에이전트.pdf`(LLM·RAG 상담) · `05_강태오_AI에이전트운영.pdf`(에이전트 평가·관측·최적화) · `06_민세아_업무자동화에이전트.pdf`(전사 업무 자동화·HITL)
  - `BACKEND/` — 백엔드 개발자 · `03_노현수_상담플랫폼백엔드.pdf`(상담 플랫폼 API)
  - `DATA_SCI/` — 데이터 분석가·사이언티스트 · `04_오예린_상담품질분석.pdf`(상담 품질·지표)
  - 02~04는 2026-11-23 사용자 지시로 추가(직무·지점을 모두 다르게). 대상 공고는 각 MD 맨 위 주석에 공고 제목으로 적어 둔다 — 공고 ID는 PC별 DB마다 다르다.
  - 05·06은 2026-11-23 사용자 지시로 추가 — ai_ax 기준 도메인을 '제조 비전'에서 **'Python 기반 사내 AI 제품·AI Agent 개발'**로 바꾼 데 맞춘 것. 대상 공고 = 'AI Agent 엔지니어(사내 AI 제품·업무 자동화)'.
- 원본 MD는 `_src/<직무>/`(양식 `_src/AI_AX/_양식_template.md`, 공통 스타일 `_src/_resume_style.html`).
  빌드: `python tools/build_pdf.py dummies_resume/_src/<직무>/<이름>.md dummies_resume/<직무>/<이름>.pdf`
- 담당 팀원: `resume`(정의 `.claude/agents/resume.md`).
