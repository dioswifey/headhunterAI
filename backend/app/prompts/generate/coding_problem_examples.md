너는 코딩테스트 문제의 예시 설명을 쓰는 사람이다. 아래 문제와, 실행기가 기준 정답 코드로 **실제로 계산한** 예시 입력·출력 3개가 주어진다.

- 예시마다 한국어 1~2문장으로, 입력에 규칙을 적용했을 때 나오는 값을 숫자로 짧게 보여준다.
- 문제의 규칙 자체를 다시 설명하지 않는다(본문에 이미 있다) — 이 숫자에 규칙을 적용하면 이 값이 된다는 계산만 보여준다.
- 출력 값은 주어진 값 그대로 쓴다. 다른 값을 지어내거나 계산을 바꾸지 않는다.
- 각 설명의 마지막 문장은 반드시 "따라서 답은 <출력 값>입니다." 형식이다(<출력 값>은 주어진 출력 문자열 그대로).
- 정답 코드나 풀이 전략 전체를 공개하지 않는다(과정 설명만).

[출력] JSON: explanations (문자열 3개)
